### **Learning Path for Manual Software Testing**  
#### **1. Foundational Concepts**  
- ** is Software Testing?**  
  Understand the purpose, objectives, and importance of testing in the software development lifecycle (SDLC). Learn key terms like errors, defects, and failures .  
  - *Resources*:  
    - **Software Testing Material’s Tutorial** ([link](https://www.softwaretestingmaterial.com/manual-testing-tutorial/)): Covers SDLC, STLC, testing principles, and types (functional, non-functional, regression, etc.) .  
    - **Great Learning’s Free Course** ([link](https://www.mygreatlearning.com/manual-testing/free-courses)): Explains manual vs. automation testing and defect lifecycle .  

- **Testing Methodologies**  
  Study static vs. dynamic testing, black-box vs. white-box testing, and levels of testing (unit, integration, system, UAT) .  

#### **2. Practical Skills Development**  
- **Test Case Design & Execution**  
  Learn to write test cases, create test scenarios, and use techniques like **Boundary Value Analysis** and **Equivalence Partitioning** .  
  - *Example Templates*: GitHub repository [Sam-rege/Manual-Test-Cases](https://github.com/Sam-rege/Manual-Test-Cases) provides real-world examples .  

- **Defect Management**  
  Master bug reporting, tracking, and tools like **Jira** (covered in free courses) .  

#### **3. Advanced Topics**  
- **Agile & Scrum**  
  Understand how testing integrates into Agile workflows. Free courses on Cursa and IT Vidhya include modules on Agile methodologies .  
- **Test Management Tools**  
  Explore tools like **TestLink** for organizing test plans and cases .
